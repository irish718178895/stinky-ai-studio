# Stinky AI Studio v0.6

Local image and video studio powered by ComfyUI, Node.js, and FFmpeg.

## New in v0.6

- 720p and 1080p output
- 24, 30, or 60 FPS
- Cut, crossfade, and dip-to-black transitions
- Smooth eased pan and zoom camera movement
- Lanczos image scaling
- Automatic NVIDIA NVENC detection with CPU fallback
- Live render stage and percentage progress
- Expanded video metadata including encoder and file size

Run `npm install`, then `npm start`. Existing `data/` projects remain compatible.
