# Stinky AI Studio v0.9 — Local Voice Studio

## Added

- Piper health check and local voice-model detection
- Per-scene narration generation and playback
- One-click generation of all missing narration tracks
- Voice speed control through Piper length scale
- Automatic invalidation of old audio when narration text changes
- Optional narration mixing during MP4 rendering
- Audio crossfades aligned with visual transitions

## Compatibility

Existing projects, images, scenes, and videos remain compatible. Voice WAV files are stored under each project in `data/projects/<project-id>/voices/`.
